# 🌿 Cotton Leaf Disease Detection App (with Treatment Advice)

This project is a prototype of a cotton disease detection web app using a deep learning model (ResNet50) and a simple Flask backend. The application allows farmers to upload images of cotton leaves and receive instant disease predictions along with treatment advice.

---

## 🔍 Features

- Upload a cotton leaf image to get a disease prediction
- Get scientifically backed treatment suggestions
- Lightweight and beginner-friendly Flask backend
- Pre-trained ResNet50 model used for demo (replaceable with custom-trained model)

---

## 🧠 Tech Stack

- **Python**
- **Flask** (Backend API)
- **TensorFlow / Keras** (ResNet50 model)
- **HTML (for frontend if extended)**
- **Mock disease-treatment mapping**

---

## 🖼️ Sample Use Case

A cotton farmer takes a photo of a leaf, uploads it to the app, and receives:
- A disease classification like `cotton_bacterial_blight`
- Recommended treatment actions
